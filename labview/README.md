# LabVIEW panel

Measurement panel for the weather station (Computer Measurement Systems).

Planned role: connect to the server as a TCP client, parse TLV frames (`docs/protocol.md`), show
measurements and send configuration commands automatically (for example to change the measurement interval).

Status: not started.
